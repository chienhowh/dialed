# Coffee List

## Goal

Show the user's current and previous coffees.

## Wireframe

```text
┌─────────────────────────────┐
│ My Coffee              ＋    │
│                             │
│ [ Active ] [ Archived ]     │
│                             │
│ ┌─────────────────────────┐ │
│ │ Ethiopia Sidama        │ │
│ │ Washed · 74158 · Light │ │
│ │ Simple Kaffa           │ │
│ │ 4 brews                │ │
│ │                     →  │ │
│ └─────────────────────────┘ │
│                             │
│ ┌─────────────────────────┐ │
│ │ Kenya Nyeri            │ │
│ │ Washed · Light         │ │
│ │ 2 brews                │ │
│ │                     →  │ │
│ └─────────────────────────┘ │
│                             │
├─────────────────────────────┤
│ Home      Coffee     History│
└─────────────────────────────┘
```

## Primary Actions

- Coffee card → Coffee Detail
- `＋` → Add Coffee

## Notes

- MVP does not require advanced filtering.
- Search can be added later if the coffee collection becomes large.
